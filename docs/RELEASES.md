从 v1.3.5 起，两套方案共用增强版号。方案 B 的应用版本仍对应官方基线 20.17.0（2620），内置增强模块使用项目版号。

v1.2.2 是基于 v1.2.1 加入底栏刷新补丁后回建的归档版。v1.3.0 使用当时已构建的方案 A 安装包。

## 附件与校验

- 从 v1.3.5 起，方案 A 附件为 `sogou-enhancer-a-<版本>.apk`，方案 B 为 `sogou-enhanced-b-<版本>.apk`，随附 `SHA256SUMS.txt`。
- 表中的校验值对应 APK 文件本身。方案 B 如果以 ZIP 提供，解压后校验。
- 官方基线为搜狗 20.17.0，APK 的 SHA-256 为 `3eb2612040fd7daefb7e92b9de5c1a715b03f272b644e0664948742df1c7a416`。v1.1.0 的官方包附件为 `sogou-20.17.0-official.zip`。

中文变更摘要见 [README 的版本历史](../README.md#版本历史)，验证范围见各版本的发布说明。

## 早期版本验证摘要

- **v1.1.0** 适配搜狗 20.17，方案 A 的原有增强钩子全部注册。方案 B 在外部模块停用时，可进行中文输入并打开底栏、剪贴板、设置和登录页。
- **v1.2.0** 通过 11 项配色检查，方案 A 和 B 的真机截图颜色与各自日志一致。
- **v1.2.1** 验证方案 A 的桌面入口与任务栈。原有 48 个 smali 类仅涉及入口适配改动。
- **v1.2.3** 验证底栏随皮肤刷新，以及方案 B 设置页可正常打开。
