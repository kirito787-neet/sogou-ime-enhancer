### 为什么需要域名重写

20.17.0 的皮肤下载请求打到 `download.sginput.qq.com/skin/skindl.php?...`，该域名已停服（404），
同一接口仍在 `srv.android.shouji.sogou.com` 提供服务。真机日志（方案 A）：

```
[SogouSkin] DL-HOST https://download.sginput.qq.com/skin/skindl.php?skin_id=1133381789&...
                   -> https://srv.android.shouji.sogou.com/skin/skindl.php?skin_id=1133381789&...
```

### 与小米版 10.32.21 的差异

小米版详情接口直接下发 `download_ssf_url`，客户端把它塞进 `ThemeItemInfo.r` 直接下载；
20.17 删掉了该字段，`r` 改作 `coinExchange`，下载改由 `skindl.php` 按 skin_id 现取。
两条路的共同点是"已购态由客户端字段决定"，所以改动点都在模型字段上，差别只在下载端点。
