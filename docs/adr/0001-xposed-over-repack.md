# ADR 0001：用 Xposed 模块而不是重打包 APK

- 状态：已采纳（2026-10-19）
- 决策者：用户 + AI

## 背景

目标是让官方普通版搜狗输入法显示 MIUI 全面屏底栏。最直觉的做法是把模块塞进搜狗 APK 再重签。

## 决策

**不修改、不重签官方 APK**，走 Xposed（LSPosed）运行时 hook。

## 依据

实测：把**完全未改动**的官方 APK 只用测试证书重签，装到设备后与改造包现象完全一致——
启动即 `SIGSEGV`。`libsogouime.so` 在 `+0xfd1a4` 处校验签名。
这个对照实验排除了"是我们的改动导致崩溃"的可能，证明崩溃源于签名校验本身。

## 后果

- 方案 A 需要 root + LSPosed，是两个 APK。
- 方案 B 若要"单 APK"，只能做**共存重打包**（改包名 `com.sohu.inputmethod.sogou.enhanced`
  + NPatch 内嵌模块），不能覆盖官方包；代价是不跟随官方更新、与官方版数据不互通。
- 无法支持无 root 设备。

## 被否方案

| 方案 | 否决原因 |
|---|---|
| 改 APK + 重签 | 签名校验 → `SIGSEGV` |
| NPatch/LSPatch 内嵌官方包名 | 同样要重签，同上 |
| Zygisk 模块 | 技术可行，但工作量远大于 Xposed，未采用 |
